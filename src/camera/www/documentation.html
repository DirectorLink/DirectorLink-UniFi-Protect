Setup

Nothing to enter here. The DirectorLink · UniFi Protect driver (the UniFi Protect Hub) adds this driver for each camera and doorbell and sets it up: run its Add New Cameras.

The Control4 camera Properties page is set by the hub: its Address is the controller, its HTTP Port the hub's picture server, with this camera's own Basic login. Control4 apps and DirectorLink take the camera's pictures from these values. Do not change them; the driver puts them back if they are changed.

Added by hand? Type the camera's name as it is in UniFi Protect into UniFi Camera, and the hub links it.

Camera off or removed? Set Camera Enabled to No: no events, alerts or pictures, and the hub stops counting it.

Detections, alerts and rings

Detections (Person, Vehicle, Animal, Package, Face, License Plate, Line Crossing, Intrusion, Motion) always fire their events, variables and contacts. Use them for automations, such as lights on for a person at night.

Alerts are for people: the Alert event, notifications and the Control4 History. A detection becomes an alert when alerts are on for this camera and on the hub, are not snoozed, the detection matches Alert On, and no alert is already active (Hold Time): one event alerts once.

Doorbells (G4 Doorbell, G4 Doorbell Pro, G6 Entry) are cameras with a ring: each press sets LAST_RING and fires Ring, whatever the alert settings. Camera Type Automatic recognizes a doorbell from the console, or at its first ring; with Camera Type Camera it never fires Ring.

Programming reference

Events

Alert, Ring, Motion Detected, Motion Ended, Person Detected, Vehicle Detected, Animal Detected, Package Detected, Face Detected, License Plate Detected, Line Crossing, Intrusion Detected, Sound Detected, Camera Online, Camera Offline, Alerts On, Alerts Off.

Variables

DIRECTORLINK_CAMERA, DIRECTORLINK_CAMERA_KIND, DIRECTORLINK_CAMERA_EVENTS, LAST_ALERT, LAST_RING, LAST_ALERT_TIME, LAST_DETECTION, LAST_SOUND (STRING); ONLINE, ALERTS_ENABLED, ALERT_ACTIVE, MOTION, PERSON, VEHICLE, ANIMAL, PACKAGE, FACE, LICENSE_PLATE, LINE_CROSSING, INTRUSION, RINGING (BOOL). Times are ISO 8601 UTC, for example 2026-10-05T18:30:00Z.

Conditionals, commands, contacts

Camera is Online · Alerts are On · Alert is Active · Motion is Active · Active detection is <type> · Last alert is <type> · This camera is a Doorbell. Commands: SET_ALERTS, SNOOZE_ALERTS, SET_ALERT_ON. Contacts (Connections → Control): Alert, Motion, Person, Vehicle, Animal, Package, Doorbell.
