## DirectorLink · UniFi Protect 1.0.1

Free, open-source Control4 driver for UniFi Protect cameras and doorbells. Part of [DirectorLink Drivers](https://directorlink.io/drivers).

DirectorLink is an independent project, not affiliated with Control4 or Snap One.

Update both files with **Driver → Add or Update Driver or Agent**. Keep the file names exactly as they are: a browser's `(1).c4z` copy installs as a separate driver. Check the downloads against `SHA256SUMS.txt`.

The first release that is not a beta. The drivers follow Ubiquiti's published Protect Integration API exactly and pass their tests against recorded API answers, but no installer has reported on them from a real UniFi system yet. Field reports are welcome: see *Field reports* in the README.

### Camera

- **DirectorLink camera agreement, version 1, complete.** New string variable **`DIRECTORLINK_CAMERA_EVENTS`**: `Alert=1` for a camera, `Alert=1,Ring=2` for a doorbell (the ids of *Alert* and *Ring* in driver.xml), so DirectorLink 1.10 finds the events without reading driver.xml. It comes after the existing variables (their order never changes) and follows the kind.
- `DIRECTORLINK_CAMERA`, `DIRECTORLINK_CAMERA_KIND` and `DIRECTORLINK_CAMERA_EVENTS` are written on every start, so they are right after a driver update too.
- A camera whose kind is `camera` (**Camera Type** set to *Camera*) never fires *Ring*.
- Every ring gets a new `LAST_RING`, later than the one before: the console's time of the press when it is within two minutes behind and five seconds ahead of the controller's clock, else the controller's time.

### Hub

- No changes apart from the version number.

### Known issues

- **Not yet confirmed on a real system.**
- **Live video needs Control4 OS 3.3.2 or newer.** Older controllers get pictures, alerts and rings.
- **Away from home** (4Sight), live video and pictures are not expected to work: their addresses are the home network's.
- **RTSPS** may not play in Control4 apps; RTSP is the default.
- **H.265:** turn off *Enhanced Encoding* in UniFi Protect for cameras Control4 should play.
- No audio, PTZ or two-way talk.
